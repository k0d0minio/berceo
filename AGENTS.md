# Start here

Read `CLAUDE.md` in this folder first. It says who we are. The router `.icm/_system/ROUTER.md` routes each request to a `CONTEXT.md` contract. Read the contract you are routed to, then only what its Inputs name. Gates are human checkboxes: read them, never tick them. Never build an orchestrator: the folders and the contracts are the pipeline.
