## Constraints

- The address (street, house_number, box) is read only inside `src/lib/famille/` (D-15); never
  on `users`, never in a response a professional or a visitor can reach.
- No health data (D-20): the context line is optional, ≤ 300 characters, with the hint; no child
  names asked for.
- The e-mail is read-only: Neon Auth cannot change it yet. No workaround in this run.
- Every word in `src/content/` to Surya's guide (D-19); DA tokens only, no red or green (D-9, D-24).
- One migration, generated by drizzle-kit, sequenced with onboarding-professionnelle's.
- `src/lib/communes/` is shared by stubs 4, 7 and 15: no family-specific code in it.
